# placitum/counter

Поведенческий инспектор Placitum. Инспекторы фазы запроса судят о намерении — что клиент прислал.
Счётчик судит о результате — что клиент **унёс**: скрейпер, перебирающий каталог честными
запросами, для сигнатур неотличим от покупателя, и отличает их только сумма.

Один subject, три фазы:

```
ответ   ──►  measure: ответ превращается в заряды корзин (сколько объектов, сколько килобайт)
запрос  ──►  judge:   уровни корзин против порогов → score | deny | действия соседям
кадры   ──►  обе работы на каждом кадре WebSocket, ось conn — до конца соединения
```

Корзины живут во внутреннем Redis контура (GCRA, та же арифметика, что у капчи). Счётчики
объявляются **на инспектор**, а не на профиль: общая секция `profiles/_shared/counters.yaml`,
пороги профилей — проценты заполнения.

Незнание — `verdict: error`: битое сообщение, чужая версия, неизвестный профиль, молчащий
Redis корзин. Измерения не было, и выбирать между пропуском и отказом счётчик не вправе — это
решает маршрут.

## Сборка

```sh
docker build -f deploy/Dockerfile -t placitum/counter .
docker buildx build -f deploy/Dockerfile -t placitum/counter \
  "https://github.com/exemt/placitum-counter.git#develop"
```

Сборка прогоняет тесты и кладёт в образ пробу: `HEALTHCHECK` шлёт обычное сообщение по шине с
профилем `_probe` и ждёт `deny`, то есть проверяет разом шину, подписку, профили и воркеров.

Что нужно рядом и все переменные — [INSTALL.md](INSTALL.md).

## Устройство

```
cmd/inspector/     шина, waf.req.counter, все фазы; ключи осей
cmd/probe/         healthcheck: профиль _probe с порогом 0
internal/buckets/  корзины GCRA
internal/measure/  правила фазы ответа: предикат → источник → заряд
internal/decide/   суд по уровням, просьбы соседей — чистые функции
internal/config/   окружение, counters.yaml, профили и горячая замена
internal/desired/  поколение из KV (policy/counter)
profiles/          _shared/counters.yaml, default, _probe
```

Общий код процессов — пульс, снимок машины, счётчики потока, уровни журнала, клиент кодера гео —
берётся из [`placitum-shared`](https://github.com/exemt/placitum-shared).

## Ветки

`develop` — то, что разрабатывается: сюда приезжает каждая выкладка. `main` — выкаченные сборки.
Правок в этом репозитории не делают: обе ветки производные от платформы.
